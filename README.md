# FLY HIGH

A static travel site for FLY HIGH, planned from Accra. Visitors can explore destinations, compare holiday packages with sample itineraries, and send a travel enquiry.

**Headquarters:** 123 Skyview Boulevard, Accra, Ghana  
**Phone:** 024 812 6060  
**Email:** hello@flyhigh.travel (placeholder — change before launch)  
**WhatsApp:** https://wa.me/233248126060

## Pages

- Home, with destination search, reasons to book, and a scrolling gallery
- Destinations, with region filters
- Tour packages, with duration, price, and day-by-day samples
- About us
- Contact, with the enquiry form and a map

Enquiries are saved in the browser only. Connect a form service before taking real bookings.
